This collection of images represents the overall development and testing process for the implementation of I²C and I3C communication protocols on FPGA. The flowcharts illustrate the finite state machine (FSM) architectures for both I²C and I3C master and slave modules, highlighting the control flow and transitions involved in address handling, data transfer, acknowledgements, and stop conditions. The system block diagram presents the top-level integration of the I3C master and slave within the FPGA environment. The oscilloscope capture displays real-time I²C bus waveform behavior observed on the physical hardware, confirming correct transmission during write operations. Hardware setup photographs show the Nexys4 DDR FPGA board configured with PMOD pin connections and ILA monitoring on the workstation used during testing. Together, these images document the functional design, implementation, and validation stages for both simulated and hardware-level evaluation of I²C and I3C protocols.
